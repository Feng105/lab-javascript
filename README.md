# lab-javascript

158.258 Web Development - JavaScript Lab (Exercises 1-4)

## Exercises

- Exercise 1: Using document.write()
- Exercise 2: The navigator object
- Exercise 3: External JavaScript file randominteger.js (randomInt 1-100)
- Exercise 4: Number guessing game (10 turns)

## How to run

Open the HTML files directly in a web browser. Exercises 3 and 4 load `randominteger.js` from the same folder, so keep the files together.
